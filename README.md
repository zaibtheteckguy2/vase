# Flower Pot/vase

A simple geometric vase/flower pot I designed in CAD. I wanted to experiment with a curvy hourglass shape and sharp vertical ridges.

## About the design
Shape: Wide base for stability, narrow waist, and a flared top rim.
Geometry: Faceted vertical ridges all the way around.
Printability: Designed with gradual angles so it shouldn't need any supports, and the continuous profile should work well in vase mode (though I haven't printed a physical test yet!).

## Files
* `.stl` – Ready to drop into a slicer.
* `.step` – Included if you want to tweak the dimensions, adjust wall thickness, or add drainage holes.

Feel free to download, scale, or remix it however you like. If you end up printing one, let me know how it turns out!
